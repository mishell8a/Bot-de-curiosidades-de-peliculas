# Bot-de-curiosidades-de-peliculas
Un bot con voz que te da curiosidades de peliculas y series de forma aleatoria 
Uso:
El bot se usa con la funcion !curiosidad, escribes esta funcion de despues espacio y la pelicula de la que quieras saber una curiosidad
Ejemplo: !curiosidad Frozen
las bibliotecas que use fueron: 
asyncio, pyttsx3, discord, unicodedata y se uso random
